## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `js/config.js` | ค่าตั้งต้น: เงิน พลังงาน ชื่อวัน/ช่วงเวลา ระดับความสนิท สภาพอากาศ ค่าสถิติ บุคลิก/หน้าตา |
| `js/data.js` | ตัวละคร สถานที่ ไอเท็ม ของสะสม ภารกิจ ความสำเร็จ ฉากจบ แชท |
| `js/engine.js` | ระบบเกมทั้งหมด (ไม่ต้องแก้เวลาเพิ่มเนื้อหา) |
| `js/events.js` | เหตุการณ์ตามสถานที่ในโหมดแผนที่ |
| `js/chapters/chapter-NN.js` | เนื้อเรื่องแต่ละบท |
| `css/style.css` | สี ฟอนต์ ลวดลาย |

## รูปแบบฉาก
```js
ชื่อฉาก: {
  where:'สถานที่', time:'เวลา', bg:'night|dawn|school|class|sunset|plain',
  text:['ย่อหน้า', 'ข้อความ {{id|กดได้สีชมพู}}', '*ความคิดในใจ*', 'ใช้ say("ชื่อ","คำพูด")',
        '# เสียงระบบ', '> จดหมาย', S => 'ข้อความตามสถานะ', {if:S=>S.flags.x, t:['เฉพาะเมื่อตรงเงื่อนไข']}],
  flav:{ wit:['ข้อความเพิ่มตามบุคลิก'] },
  hot:{ id:{ t:['ผลเมื่อกด'], fx:{...} } },
  choices:[{ t:'ตัวเลือก', if:S=>..., lock:'เหตุผลที่ล็อก', hide:true, fx:{...}, res:['ผลลัพธ์'], go:'ฉากถัดไป' }],
  next:'ฉากถัดไป'   // หรือ '@hub' แผนที่ · '@advance' ช่วงเวลาถัดไป · 'บท.ฉาก'
  chEnd:{summary, hook}  // ฉากปิดบท
}
```
**fx** (ผลลัพธ์): `stat:{conf:+3}` `rel:{kaleo:+1}` (ความสนิท) `heart:{kaleo:+1}` (ใจเต้น) `money:+10, why:'..'` `item:'id'` `useItem` `flag:'x'` `set:{k:v}` `unlock:'locId'` `collect:{food:'poke'}` `meet:'npcId'` `diary:'บรรทัดไดอารี่'` `chat:{who,msgs,ask}` `ach:'id'` `fn:(S)=>{}`

## เพิ่มเนื้อหา
- **บทใหม่**: คัดลอก `chapter-04.js` เป็น `chapter-05.js` เปลี่ยน `id:'ch05'` → เพิ่ม `<script>` ใน `index.html` → เพิ่ม `'ch05'` ใน `chapterOrder` (config) → ให้ฉากสุดท้ายของบทก่อนหน้า `next:'ch05.ชื่อฉากแรก'`
- **ตัวละคร**: เพิ่มใน `DATA.npcs` (`rel:true, romance:true` = มีคะแนน/จีบได้)
- **สถานที่**: เพิ่มแถวในลิสต์ `L` ของ `data.js` (`[id, ชื่อ, emoji, โซน, เปิดตั้งแต่เริ่ม?, กลางแจ้ง?]`)
- **เหตุการณ์แผนที่**: เพิ่มใน `events.js` (กำหนด loc/slots/days/weather/if/once/prio)
- **ความสำเร็จ / ฉากจบ**: เพิ่มใน `data.js` แล้วเรียก `fx:{ach:'id'}` หรือ `'@ending:e_id'`

## บันทึกการตัดสินใจ
- ใช้บุรุษที่สองเรียก "เธอ" (อ่านลื่นกว่า "คุณ" ในภาษาไทย)
- **ริโอ** (ผู้ช่วยครู/นักศึกษา) เป็นพี่ที่ปรึกษา ไม่มีเส้นโรแมนติก ตัวละครโรแมนติกทุกคนเป็นนักเรียนวัยรุ่น และเนื้อหาจำกัดที่ระดับน่ารัก
- ตัวละคร NPC ที่ยังไม่ลงเรื่อง (มาคัว ลูคัส เอเธน เคนจิ ไอคาไอ ฮาโลอา นิก เคียน) ถูกเตรียมไว้ในข้อมูลแล้ว จะเข้าเรื่องเต็มในบท 5+
- เซฟเก็บจุดเริ่มต้นของฉากปัจจุบัน (กดสีชมพูซ้ำได้) เพื่อป้องกันเซฟพัง
